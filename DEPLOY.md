# Развёртывание

Инструкция самодостаточна: подходит и человеку, и LLM-агенту. Все команды выполняются из корня репозитория.

## 1. Зависимости

| Зависимость | Версия | Обязательна | Зачем |
|---|---|---|---|
| Node.js | ≥ 22 (проверено на 22.22) | да | сервер и клиент; используется только stdlib, `npm install` не нужен |
| `openssl` в `PATH` | любая | нет | автовыпуск самоподписанного сертификата для HTTPS в локальной сети. Входит в Git for Windows. Без него сервер работает по HTTP |
| Python + `openpyxl` | 3.11+, `openpyxl==3.1.5` | нет | только `tools/extract.py` — пересборка `data/default_config.json` из Excel в `source/` |

npm-зависимостей нет: `package.json` нужен ради версии и скриптов, `package-lock.json` отсутствует намеренно.
Python-зависимости — в `requirements.txt`.

```bash
node -v                                   # должно быть v22+
python -m pip install -r requirements.txt  # опционально, только для extract.py
```

## 2. Запуск

```bash
git clone https://github.com/Alkores/Global_AI.git
cd Global_AI
node server.js
```

В консоли печатаются ссылки (HTTP и HTTPS по всем IP машины) и `ADMIN_TOKEN`, если он не задан руками.
По умолчанию: игра — `http://localhost:3000`, админка — `http://localhost:3000/admin`, HTTPS — `https://localhost:3443`.

Что создаётся при первом запуске (всё в `.gitignore`, в репозиторий не попадает):

| Путь | Содержимое |
|---|---|
| `data/config.json` | рабочая копия конфига из `data/default_config.json`; правится в админке |
| `data/rooms.json` | состояние комнат, переживает перезапуск сервера |
| `certs/server.{crt,key}` | самоподписанный сертификат (если найден `openssl`) |

Переменные окружения:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PORT` | `3000` | порт HTTP |
| `HTTPS_PORT` | `3443` | порт HTTPS |
| `ADMIN_TOKEN` | генерируется и печатается | пароль админки |
| `NO_HTTPS=1` | — | отключить HTTPS целиком |
| `TLS_KEY`, `TLS_CERT` | — | свои ключ и сертификат (автогенерация их не трогает) |
| `EXTRA_SAN` | — | доп. записи в SAN, напр. `IP:10.0.0.5,DNS:myhost` |
| `CERT_DAYS` | `825` | срок сертификата |
| `OPENSSL` | из `PATH` | путь к `openssl` |

```bash
PORT=8080 ADMIN_TOKEN=секрет node server.js   # свой порт и пароль админки
NO_HTTPS=1 node server.js                     # только HTTP
node server.js --regen-cert                   # перевыпустить сертификат и выйти
```

## 3. Проверка после развёртывания

```bash
node tools/selfcheck.js   # формулы против Excel, переход года, регрессии — должно закончиться «ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ»
node tools/smoke.js       # сам поднимает сервер, два бота играют партию до 2040 (~30 с)
```

Сквозной сценарий против уже запущенного сервера:

```bash
PORT=3111 ADMIN_TOKEN=test node server.js &
BASE=http://localhost:3111 node tools/e2e.js
```

Те же команды через npm-скрипты: `npm start`, `npm test`, `npm run smoke`, `npm run e2e`.

## 4. Игра по локальной сети (телефоны, планшеты)

1. Запустить `node server.js` и взять из консоли строку `с телефона: https://<IP>:3443/`.
2. Телефон — в той же Wi-Fi-сети; Windows Firewall при первом запуске Node разрешить для частных сетей.
3. Сертификат самоподписанный — браузер один раз покажет предупреждение, нужно принять («Дополнительно» → «Перейти на сайт»).
   Как импортировать сертификат в доверенные на Windows / Android / iOS — в `README.md`.

## 5. Обновление версии

Версия игры = версия правил, живёт в `package.json` и в теге. Порядок:

1. Внести изменения, описать их в `CHANGELOG.md` в секции `[Unreleased]`.
2. Поднять `version` в `package.json`, перенести записи в новую секцию с датой.
3. `git commit`, затем `git tag -a vX.Y.Z -m "..."` и `git push origin main --follow-tags`.

## 6. Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| `SyntaxError` при старте | Node старше 22 — обновить |
| HTTPS-ссылка не печатается | нет `openssl` в `PATH` — поставить или задать `OPENSSL`, либо играть по HTTP |
| `EADDRINUSE` | порт занят — задать `PORT` / `HTTPS_PORT` |
| Телефон не открывает страницу | другая сеть или блок Firewall; проверить `https://<IP>:3443/` именно с IP из консоли |
| Админка не принимает токен | `ADMIN_TOKEN` сгенерирован при старте — взять из консоли или задать своим значением |
| Карта не отрисовалась, видны цветные чипы | нет доступа к `cdn.jsdelivr.net` (d3 + topojson) — это предусмотренный фолбэк, игра работает |
| Конфиг сломан после правок в админке | удалить `data/config.json` и перезапустить — он пересоздастся из `data/default_config.json` |
| `ModuleNotFoundError: openpyxl` | `python -m pip install -r requirements.txt`; для самой игры Python не нужен |
| `extract.py` даёт конфиг, отличный от закоммиченного | известное расхождение исходных Excel-книг, см. примечание в `README.md`; закоммиченный `data/default_config.json` считается эталоном |
